# Gin ClearJoypad

The Japanese release `gin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one structurally verified ROM0 `ClearJoypad` immediately after the joypad interrupt `RETI` placeholder. Per-release evidence records the routine address, both HRAM destinations and code hash without publishing ROM bytes. Korean precedes English where available, and candidate status is preserved.
