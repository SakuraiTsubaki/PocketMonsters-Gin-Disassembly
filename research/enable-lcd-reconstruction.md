# Gin EnableLCD

The Japanese release `gin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one ROM0 implementation that reads FF40, sets LCDC bit 7, writes FF40 and returns. Evidence preserves release identity, address and code hash without ROM bytes. Korean precedes English where available; release status is unchanged.
