# Pocket Monsters Gin SkipNames and AddNTimes

The Japanese release `gin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one adjacent routine pair. Japanese builds use NAME_LENGTH 6; Korean and the other official localizations use 11. Each release records both addresses, the immediate length and pair hash without ROM bytes. Korean precedes English where available; release status is unchanged.
