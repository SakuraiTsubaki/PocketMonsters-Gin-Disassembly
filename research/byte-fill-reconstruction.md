# Gin `ByteFill` disassembly

The Japanese release `gin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one ROM0 implementation of the same 12-byte routine. The committed RGBDS source reconstructs its split 8-bit countdown, including the zero-length no-op case. Per-release reports retain ROM identity, address and code hash without publishing ROM bytes. Candidate/verified release status is preserved from `research/releases.csv` and is not promoted by this function match.
