# Pocket Monsters Gin IsInArray

The Japanese release `gin-jp-rev0` is the origin reference. All 8 cataloged releases (Japanese, Korean, English, German, Spanish, French, Italian) contain exactly one ROM0 implementation with the same nineteen-byte code hash. The routine searches the first byte of DE-sized entries, stops at 0xff, returns the index in B, and reports a match through carry. No ROM bytes are published. Korean precedes English where available; release status is unchanged.
