# Initial ROM Survey

This document records the first structural survey of the eight read-only Pokémon Silver source ROMs used to reconstruct this repository. ROM binaries are not committed.

## Confirmed source set

- JP Rev 0 and JP Rev A: 1 MiB / 64 × 16 KiB ROM banks.
- Korean, English USA/Europe, German, French, Italian, and Spanish: 2 MiB / 128 × 16 KiB ROM banks.
- All eight images have valid Game Boy header and global checksums.
- All use cartridge type `0x10` (`MBC3+TIMER+RAM+BATTERY`) and RAM size code `0x03` (32 KiB).
- Japanese Rev A reports header version 1; all other inputs report version 0.
- Korean Silver uses CGB flag `0xC0`, while the other seven inputs use `0x80`. Korean Silver also has SGB flag `0x00`; the others use `0x03`.

## Same-index banks identical across all eight releases

`0C, 2A, 30, 37, 3B, 3C, 3D`

These banks are high-value candidates for a single shared source representation, subject to semantic verification. Byte identity alone does not determine final source ownership.

## Japanese revision delta

JP Rev 0 and Rev A differ in 19,150 bytes spread across 16 banks. Changed banks:

`00` (179), `01` (103), `03` (5), `04` (60), `05` (2), `09` (82), `0A` (1), `0B` (7), `0F` (160), `14` (2), `21` (2), `23` (10,787), `24` (1), `25` (60), `3E` (79), `3F` (7,620)

Bank 00 alone differs by 179 bytes.

## Bank 00 status

Bank 00 is not byte-identical between language releases. Pairwise differences are recorded in `analysis/bank00_pairwise_diffs.csv`. This means Bank 00 should be reconstructed as shared engine logic plus release-specific data/patch points rather than copied as one opaque bank.
